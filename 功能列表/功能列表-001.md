# 功能列表-001

条目键 = 代码文件名(主键取 L2/L3 流程文件);状态:✅完成 / 🔧待校准 / ⏳待验证。

## L0 公理层

- `AppSettings.cs` ✅ 应用设置模型:游戏路径、超时、收取后行为、主题、窗口匹配规则。
- `CraftPlan.cs` ✅ 设施枚举 `FacilityKey` 与制造计划 `CraftPlanConfig`(四设施)。
- `RunState.cs` ✅ 运行期状态:`FacilityPhase`、`EngineMode`、`ScheduleState`、`RunReport`。
- `AnchorTable.cs` ✅ 归一化锚点模型 + `PixelMapper`(比例↔物理像素换算,含 ROI 夹取)。
- `ItemCatalog.cs` ✅ 可制造物品目录(计划页候选)。
- `StepFailedException.cs` ✅ 步骤失败异常(携带失败截图与 OCR 转储路径)。
- `Ports.cs` ✅ `INotifier` / `IClock` / `SystemClock` / `CapturedFrame`。

## L1 组件层

- `GameProcessBrick.cs` ✅ 启动游戏、按窗口关闭进程树(先礼后兵)。
- `GameWindowBrick.cs` ✅ 找窗、客户区屏幕矩形、前台化、16:9 断言、候选窗口枚举。
- `ScreenCaptureBrick.cs` ✅ GDI BitBlt 截图(BGRA 顶行在前)、PNG 保存。
- `OcrBrick.cs` 🔧 中文 OCR(ROI 裁剪+放大+识别,行中心回映射);缺语言包明确报错。
- `InputBrick.cs` ✅ SendInput 绝对坐标点击/移动/滚轮/ESC;虚拟桌面归一化;被拒即抛错。
- `CountdownParser.cs` ✅ 倒计时解析(冒号 / 中文;OCR 形近字折算);失败即 false。
- `SleepGuardBrick.cs` ✅ 常驻线程持有防睡眠请求(ES_CONTINUOUS 线程绑定语义)。
- `AutostartBrick.cs` ✅ schtasks 开机自启(/RL HIGHEST 免 UAC);失败带退出码抛出。
- `JsonStoreBrick.cs` ✅ JSON 原子写、损坏明确报错、`LoadOrCreate` 仅缺文件时落默认。
- `AppDataBrick.cs` ✅ `%LocalAppData%\DeltaCrafter` 目录规划与默认数据落地。
- `Win32/Native*Api.cs` ✅ 窗口/截图/输入/电源 P/Invoke 声明。

## L2 流程层

- `ScreenProbe.cs` ✅ 截图+OCR+点击原语:界面判定(含单帧多界面 WhichScreen)、区域读取、按名找行、滚动、失败转储。
- `StepRunner.cs` ✅ 步骤执行器(动作+轮询校验+超时+1 次重试+失败留现场),唯一失败出口。
- `LaunchFlow.cs` ✅ 就绪链:找窗/启动/前台/16:9 → 模式选择(点烽火地带)→ 基地(Tab)→ 大厅(有界 ESC 关弹窗)。
- `SpecOpsNavFlow.cs` ✅ 大厅顶栏进入特勤处(总览一屏含四槽位,无需逐设施导航)。
- `CollectFlow.cs` ✅ 单帧观察四槽位(空闲中/倒计时/物品名归类)+ 领取(直达结算或经生产页「领取」,双分支显式校验)。
- `CraftStartFlow.cs` ✅ 点槽位进生产页→按名定位(限 6 页滚动)→三态按钮分支(生产/一键补齐/中止)→按钮变「中止」即开工→读剩余时间。
- `ShutdownFlow.cs` ✅ 收取后处置:关闭进程 / 最小化(仅成功路径)。
- `ScheduleEngine.cs` ✅ 下次执行计算(取最早需求点)、状态持久化、失败退避闸门。
- `CatalogScanFlow.cs` ✅ 配方目录扫描:滚动读全列表,OCR 名称经 ICatalogSink 合并进 items.json(与玩家解锁一致)。
- `AbortFlow.cs` ✅ 中止制造:进设施→校验按钮确为「中止」才点→确认弹窗(点右侧「中止」)→校验回空闲。abort-confirm 已按实机截图标定(rev6)。
