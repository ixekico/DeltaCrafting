# 需求历史-001

## 需求 R001 · 三角洲特勤处自动制造助手(2026-07-26)

原始描述:制作一个项目,可自动打开游戏《三角洲行动》(先设定游戏路径),打开特勤处制作设定好的
物品;定时在上一轮物品制造好时自动上游戏领取,再制作下一批。UI 参照 OpenSteamEYA,采用
Windows 11 原生 Fluent Design、Mica 云母、左侧 NavigationView、自定义沉浸式标题栏、圆角卡片、
系统主题资源与强调色、深浅色自动切换、全程无尖角、界面克制留白充足。实现要求:先查技术栈不立即改;
Windows 原生优先 WinUI 3 + Windows App SDK;优先原生控件与主题资源、不引大型第三方 UI 库;
使用 MicaBackdrop/NavigationView/系统 Card 颜色/AccentButtonStyle;抽取统一颜色/圆角/间距/文字
层级资源;保留现有业务逻辑只重构 UI 层;先给结构再实现;完成后构建并检查深浅色/缩放/DPI。

确认决策(2026-07-26):
- 现有项目:空文件夹,全新开始。
- 游戏平台:国服 PC 客户端,直接按路径启动(已记住账号,可自动进大厅)。
- 分辨率:任意 16:9,采用相对坐标,不引入 OpenCV。
- 收取后行为:可配置,默认收完即关(省资源)。

关键取舍:
- 无官方远程接口(官方小程序仅制造完成提醒),只能走「启动客户端 + 画面识别 + 模拟点击」。
- WinAppSDK 选 1.7.x 而非最新 2.x:1.7 确切支持 .NET 8,2.x 的 .NET 8 支持不明确,不冒构建失败风险。
- 时间依据用游戏内倒计时 OCR,不用静态时长表(受特勤处等级影响会漂移)。
- 坐标全部归一化存 anchors.json,可手改热重载,游戏改版通常只需重校准不改代码。

## 需求 R003 · 识别当前任务(2026-07-26)

原始描述:总览界面「开始制造」和「停止」中间加「识别当前任务」——新用户第一次用时
特勤处可能已经在制造东西了,得识别上并同步时间。

## 需求 R004 · 物品选择搜索(2026-07-26)

原始描述:制造计划的物品选择栏应附带搜索,比如想造 7.62x39mm AP,输 AP(不区分大小写)
应把 AP 相关子弹都列出来。

## 需求 R005 · 总览显示规范物品名(2026-07-26)

原始描述:不应把识别原文直接放总览,应和现有物品数据库比对,把数据库中的正确物品
呈现在总览里——不然「7毛2」是什么东西。

## 需求 R006 · 误判修正与时间校准(2026-07-26)

原始描述:制药台明明没有制造好为什么识别成制造好了;其次识别出来的时间要减一秒,

## 需求 R007 · 预启动(2026-07-26)

原始描述:为了算上游戏启动时间,应该在每一个预计制造完成时间点的前两分钟检测游戏
进程是否打开,没打开的话应该提前打开。
## 需求 R008 · GitHub 首次发布收尾(2026-07-27)

原始描述：项目已经基本完备，准备发布到 GitHub；继续完善直到达成发布需求。

确认决策：
- 发布目标包含公开仓库说明、可复现构建、自动测试、Windows x64 发布包与 SHA-256。
- 现有动漫图标继续使用；不采用新生成的原创候选图标。
- 在版权持有人明确选择开源许可证前，采用保留全部权利的保守发布状态。
- 本机 `HANDOFF.md` 含诊断路径与临时状态，不纳入公开仓库。

完成标准：
- 最新源码构建与测试通过。
- 本机发布脚本与 GitHub Actions 使用相同的失败语义和发布命令。
- 发布压缩包不包含日志、用户配置、截图、构建缓存或内部交接文档。
- 远程 GitHub 仓库、首个标签与 Release 可访问。

## 需求 R009 · Setup 与卸载程序发布修正(2026-07-27)

原始描述：审查 Claude 完成的 Inno Setup 方案，补齐发布前缺项并开始修正。

确认决策：
- 保留 Inno Setup 6，但固定为官方签名的 6.7.3；编译器和中文语言文件均校验 SHA-256。
- 中文界面是发布输入，不允许缺失时回退英文；`-SkipBuild` 必须验证 payload 真实版本。
- 静默卸载必须无自定义提示并保留数据；交互删除只在应用卸载完成后执行。
- 进程结束或自启任务清理失败必须停止主流程并暴露具体退出码。

完成标准：
- GitHub Release 同时上传 Setup、免安装 ZIP 与各自 SHA-256。
- Setup 能在托盘进程运行时安装，生成卸载程序并注册到 Windows 应用列表。
- 静默卸载删除安装目录、卸载注册项和自启任务，同时保持本机数据逐文件不变。
