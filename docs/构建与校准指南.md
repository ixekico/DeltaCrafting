# 构建与校准指南

## 一、环境准备(仅需一次)

1. Windows 11(需 Mica 云母效果;Windows 10 可运行但标题栏背景回退纯色)。
2. 安装 **.NET 8 SDK**(x64)。
3. 安装 Visual Studio 2022(勾选「.NET 桌面开发」+「Windows 应用 SDK C# 模板」),
   或仅用命令行 SDK + 手动还原。
4. 安装 **简体中文 OCR 组件**:Windows 设置 → 时间和语言 → 语言和区域 →
   中文(简体) → 语言选项 → 安装「光学字符识别」。缺此组件程序会在启动时明确报错。

## 二、构建

命令行(在解决方案根目录):

```powershell
dotnet restore DeltaCrafter.sln
dotnet build DeltaCrafter.sln -c Release -p:Platform=x64
```

跑纯逻辑单元测试(倒计时解析、锚点换算、调度计算、JSON 读写):

```powershell
dotnet test tests/DeltaCrafter.Core.Tests/DeltaCrafter.Core.Tests.csproj -p:Platform=x64
```

生成可分发的自包含目录(免安装运行时,双击即用):

```powershell
dotnet publish src/DeltaCrafter.App/DeltaCrafter.App.csproj -c Release -r win-x64 --self-contained -p:Platform=x64
```

Visual Studio:打开 `DeltaCrafter.sln`,配置选 `Release | x64`,将 `DeltaCrafter.App` 设为启动项目,F5。

> 本程序清单要求**管理员权限**:游戏客户端通常提权运行,普通权限的模拟点击会被系统静默丢弃。
> VS 需以管理员启动才能 F5 调试。

## 三、首次运行与设置

1. 启动后进入「设置」页:
   - **游戏路径**:选择《三角洲行动》启动器 / 游戏可执行文件。
   - **游戏窗口**:先手动把游戏打开到任意界面,点「定位窗口…」,在列表里选中游戏窗口并「绑定」
     (把标题+类名固化为匹配规则,避免猜测)。
   - 其余按需:启动超时、进入大厅超时、收取后行为(默认收完即关)、失败重试间隔、防睡眠、主题等。
2. 到「制造计划」页:为每个设施打开开关并填写**制造物品名称**(需与游戏内列表显示名完全一致)。
3. **游戏内显示设置改为 16:9 无边框窗口**(如 1920×1080 / 2560×1440);非 16:9 会被明确拒绝。

## 四、锚点校准(关键,决定点击是否准确)

> **当前状态:已预标定。** anchors.json 已按 2560×1440 实机截图完成全量标定，
> 并用 14 个 1920×1080 关键页面/状态完成实际 OCR 与锚点回放
> (calibrated=true,坐标为归一化比例,任意 16:9 分辨率通用)。正常情况下无需再校准;
> 仅当游戏版本更新改了界面布局、或实测某一步点偏时,按下述方法微调对应条目即可。
> 注意:运行时读取的是 `%LocalAppData%\DeltaCrafter\anchors.json`(首次运行从程序目录复制);
> 新版本默认表修订号更高时会先备份再自动替换本地副本。

1. 手动把游戏开到**特勤处某设施页**。
2. 总览页 →「单步调试」→「截图并识别当前画面」。程序把整帧截图与全文 OCR 存到
   `%LocalAppData%\DeltaCrafter\shots\`(日志页有「打开截图文件夹」按钮)。
3. 用任意看图工具读出你要标注的**像素坐标**,换算成比例填入 anchors.json:
   - 点位 `points`:`x = 像素X ÷ 画面宽`,`y = 像素Y ÷ 画面高`(画面宽高 = 客户区像素,不含标题栏)。
   - 区域 `rois`:`x,y` 为左上角比例,`w,h` 为宽高比例。
4. 逐界面标注:大厅入口、特勤处四个设施页签、每个设施的「状态文字区 state-text / 倒计时区
   countdown / 领取按钮 collect / 打开制造 open-craft」、配方列表「列表区 list-area / 开始制造
   confirm-craft / 材料不足提示区 insufficient-flag」、领取结算「关闭点 dismiss」。
5. 核对 `keywords`(可领取/制造中/空闲/材料不足)与游戏实际措辞一致。
6. 全部填好后把 `calibrated` 改为 `true`,保存。程序会按文件修改时间自动热重载,无需重启。

> 建议逐段验证:先用「仅启动到大厅」确认能识别大厅,再「进入特勤处」,最后才「立即执行一轮」。
> 每一步失败都会在 `shots\` 留下带 `fail-` 前缀的现场截图与 `.txt` OCR 转储,便于定位是哪个锚点不准。

## 五、完成后自检清单

界面:深色 / 浅色 / 跟随系统三种主题切换正常;100% / 125% / 150% DPI 与跨屏拖拽下布局不破、
Mica 生效;所有控件、卡片、弹窗、托盘菜单均为圆角、无尖角。

功能:托盘最小化与恢复;开机自启开关(计划任务,最高权限、不弹 UAC);防睡眠;
「单步调试」各流程;完整一轮(领取→续造→按倒计时定时唤起下一轮)。

> 游戏大版本更新导致 UI 变化时,通常只需重新校准 anchors.json,不必改代码。
